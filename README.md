# 📒 **ZSHRC-CONFIG**

Superior ZSH configuration and startup, supporting multiple dynamic hosts and environments.

**Backup your current `~/.zshrc` file and leave new/current version containing only:**

```sh
source "$HOME/.zshrc-config/main.zsh";
```
